About

I'm a software, DevOps, and automation engineer with 10+ years across software delivery, production operations, infrastructure, networking, databases, and engineering automation. I've never really been a narrow tech person. I tend to work wherever the problem leads: building software and internal tools, working with APIs and databases, automating repetitive work, improving CI/CD and releases, troubleshooting production systems, and figuring out how to make things easier for the next person who has to work with them.

In my current role, I designed the standardized .NET CI/CD and release model for an approximately 60-application estate, built Azure DevOps automation and deployment guardrails, support and troubleshoot C#/.NET applications, handle production releases and database migrations, and investigate issues across applications, APIs, databases, identity, configuration, infrastructure, and networking. I also build Python automation and FastAPI dashboards for operational workflows and engineering visibility, and work with Go for API development.

My hands-on stack includes Python, FastAPI, Go, C#/.NET, JavaScript, HTML/CSS, PowerShell, SQL Server, REST APIs, Azure DevOps, GitHub Actions, IIS, Azure Monitor, Application Insights, KQL, and Azure Key Vault. I've also built security-focused tooling for credential discovery and remediation across 100+ repositories, Key Vault migration and rollback, PII safeguards, audit-focused workflows, and internal applications that sit somewhere between software engineering, DevOps, and production tooling.

I'm pursuing an M.S. in Cyber Defense at Dakota State University, which has been a good way to add more security depth to the development and operations work I already do. I also spend a lot of my own engineering time experimenting with AI-enabled development and automation, including agent workflows, engineering knowledge systems, incident triage, APIs, and human-reviewed AI execution.

I'm open to remote roles across software engineering, backend development, DevOps, platform engineering, automation, production engineering, internal tooling, developer productivity, and AI-enabled engineering. The common thread is pretty simple: I like building useful things, automating work that shouldn't be manual, figuring out why something broke, and making systems easier to build, ship, and operate.
